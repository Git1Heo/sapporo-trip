떠나기 전 예약·발권 가이드

공항↔노보리베츠 구간의 JR 특급열차, 1일차에 이용할 도난버스, 그리고 2일차 노보리베츠→삿포로 구간에서 이용할 유유라이너(호텔 직행 셔틀) 예약 방법을 미리 정리했어요. 모두 한국에서 스마트폰으로 예약 가능합니다.

JR특급열차 (전 구간 공통) — 지정석권 발권

  1. 가장 간단한 방법은 당일 역 발매기: 신치토세공항역·노보리베츠역·삿포로역 모두 한국어 지원 지정석 발매기가 있어 구간·시간만 고르면 바로 발권돼요.
  2. 성수기·특정 시간대를 놓치기 싫다면 JR 홋카이도 에키넷(えきねっと)에서 사전 예약 — 사이트/앱 회원가입 → 승차구간·날짜·열차 선택 → 신용카드 결제.
  3. 에키넷으로 예약했다면 승차 전 반드시 지정석 발매기(지정석마크)에서 예약번호 입력 → 실물 승차권으로 교환(결제한 카드 지참).
  4. 교환한 승차권(자유석 승차권 + 지정석권 2장)을 개찰구 통과 시 함께 넣거나 태그.
TIP 사전 예약이 필수는 아니에요. 사람이 몰리는 금·토 오후만 아니면 당일 발매기로도 충분합니다.
↳ JR 홋카이도 공식 홈페이지 (한국어)

Bus도난버스 직행 에어포트호 — 완전 예약제

  1. 도난버스 공식 홈페이지(donanbus.co.jp) 접속 → 한국어 페이지에서 "고속 노보리베츠 온천 에어포트호" 노선 선택.
  2. 승차일(10/5)·승차 정류장(신치토세공항 국제선 1층)·인원 입력 후 원하는 시간대(예: 15:10발) 선택.
  3. 이름·연락처 입력 후 신용카드로 결제 — 완전 예약제라 당일 현장 구매는 좌석이 없으면 불가할 수 있어요.
  4. 결제 완료 메일의 예약번호(QR)를 캡처/저장 → 당일 승차 시 기사에게 제시.
  5. 운행 편수가 하루 몇 편뿐이라 늦어도 출발 1~2일 전에는 예약하는 걸 추천해요.
TIP 왕복으로 끊으면 소폭 할인되는 경우가 있어요. 예약 화면 스크린샷과 실제 예시가 궁금하면 아래 후기 글을 참고하세요.

2일유유라이너 — 노보리베츠→삿포로 호텔 직행 셔틀

  1. 유유라이너는 노보리베츠 온천가의 료칸·호텔 앞에서 삿포로 시내(삿포로역 인근)까지 환승 없이 데려다주는 예약제 셔틀버스예요. 역까지 짐 들고 이동할 필요가 없는 게 최대 장점.
  2. 예약은 유유라이너 오퍼레이션센터(☎ +81-11-223-1888, 접수시간 9:00~18:00 연중무휴) 전화 또는 온라인 예약 페이지에서 진행.
  3. 승차일·인원·픽업 호텔(노보리베츠 그랜드호텔)·하차 희망지(삿포로역 인근)를 지정하고 예약을 확정.
  4. 예약 확인서(또는 예약번호)를 당일 호텔 로비/픽업 장소에서 기사에게 제시하면 OK.
